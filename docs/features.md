# 기능 리스트

카페인 트래커 서비스가 현재 제공하는 기능 목록. (서버 구현 기준, 2026-09-01)

| 번호 | 분류 | 기능 | 설명 | 화면 |
|---|---|---|---|---|
| 1 | 인증 | 회원가입 | 이메일·비밀번호로 계정을 생성한다 | 회원가입 화면 |
| 2 | 인증 | 로그인 | 이메일·비밀번호 검증 후 Access/Refresh 토큰을 발급한다 | 로그인 화면 |
| 3 | 인증 | 토큰 재발급 | Refresh 토큰으로 만료된 Access 토큰을 재발급한다 | (화면 없음 — 자동) |
| 4 | 인증 | 로그아웃 | 서버에 저장된 Refresh 토큰을 무효화한다 | 설정 화면 |
| 5 | 사용자 | 내 정보 조회 | 로그인한 사용자의 식별자·이메일을 조회한다 | 설정 화면 |
| 6 | 설정 | 설정 조회 | 반감기·건강 상태·취침 시각·기준 용량·자동 학습 여부와 학습 상태를 조회한다 (최초 접근 시 기본값 생성) | 설정 화면 |
| 7 | 설정 | 설정 변경 | 설정 전체를 갱신한다. 반감기 변경 시 학습 prior가 리셋된다 | 설정 화면 |
| 8 | 카페인 | 카페인 기록 추가 | 음료명·카페인량(mg)·섭취 시각을 기록한다 | 기록 입력 화면 |
| 9 | 카페인 | 카페인 기록 수정 | 기존 기록의 음료명·카페인량·섭취 시각을 수정한다 | 기록 입력 화면 |
| 10 | 카페인 | 카페인 기록 삭제 | 기존 기록을 삭제한다 | 홈 화면 |
| 11 | 카페인 | 오늘 기록 조회 | 오늘(로컬 새벽 5시 이후)의 카페인 기록 목록을 조회한다 | 홈 화면 |
| 12 | 카페인 | 오늘의 카페인 현황 | 잔류량 시계열 차트(15분 간격)·현재 잔류량·취침 시 예상 잔류량·총 섭취량(400mg 초과 여부)·섭취 마감시각을 서버가 계산해 제공한다 | 홈 화면 |
| 13 | 수면 | 수면 샘플 업로드 | 기기에서 읽은 HealthKit 원시 수면 샘플을 배치 업로드한다 (멱등 처리) | (화면 없음 — 자동 동기화) |
| 14 | 수면 | 수면 요약 조회 | 원시 샘플을 서버가 병합해 총 수면 시간·침대 시간·수면 효율·수면 잠복기(SOL)·단계별 시간을 계산해 제공한다 | 수면 화면 |
| 15 | 학습 | 반감기 학습 실행 | 최근 7일의 미학습 밤에 대해 카페인 잔량과 수면 잠복기로 개인 반감기를 베이지안 학습하고 설정에 반영한다 | (화면 없음 — 자동 실행) |
| 16 | 학습 | 학습 관측 이력 조회 | 날짜별 학습 관측 기록을 조회한다 | 학습 대시보드 화면 |
| 17 | 학습 | 학습 대시보드 | 최신 반감기 추정(95% 신뢰구간·신뢰도)·모델 정확도(R²·RMSE)·잔량/SOL 히스토그램을 서버가 계산해 제공한다 | 학습 대시보드 화면 |
