# 기능 리스트

카페인 트래커 서비스가 현재 제공하는 기능 목록. (서버 구현 기준, 2026-09-25)

| 화면 | 기능 | 설명 |
|---|---|---|
| 회원가입 화면 | 회원가입 | 이메일·비밀번호로 계정을 생성하고 기본 설정을 함께 만든다 (같은 이메일 동시 가입은 하나만 성공·나머지는 중복 이메일) |
| 로그인 화면 | 로그인 | 이메일·비밀번호 검증 후 Access/Refresh 토큰을 발급한다 (같은 이메일로 15분 안에 5번 실패하면 그 15분이 끝날 때까지 거절·막힌 동안은 맞는 비밀번호도 거절·없는 이메일도 같은 규칙과 같은 응답 시간·성공하면 실패 횟수 초기화) |
| (화면 없음 — 자동) | 토큰 재발급 | Refresh 토큰으로 만료된 Access 토큰을 재발급한다 |
| 설정 화면 | 로그아웃 | 그 사용자의 Refresh 토큰을 모든 기기에서 무효화한다 |
| 설정 화면 | 내 정보 조회 | 로그인한 사용자의 식별자·이메일을 조회한다 |
| 설정 화면 | 설정 조회 | 반감기·건강 상태·취침 시각·기준 용량·자동 학습 여부와 학습 상태를 조회한다 (가입 시 기본값 생성·설정 행이 없는 기존 계정은 첫 조회 시 생성·가입 직후 동시 조회도 전부 성공) |
| 설정 화면 | 설정 변경 | 설정 전체를 갱신한다. 반감기 변경 시 학습 prior가 리셋된다 (같은 사용자의 학습 실행·수면 업로드가 진행 중이면 끝난 뒤 반영) |
| 설정 화면 | 알림 설정 | 알림 종류별(섭취 마감·취침 잔량 예고·기록 리마인더·카페 근처) on/off를 설정에 저장한다 (카페 근처는 기본 꺼짐, 요청에서 생략하면 기존 값 유지) |
| 기록 입력 화면 | 카페인 기록 추가 | 음료명·카페인량(mg)·섭취 시각을 기록한다 |
| 기록 입력 화면 | 카페인 기록 수정 | 기존 기록의 음료명·카페인량·섭취 시각을 수정한다 |
| 홈 화면 | 카페인 기록 삭제 | 기존 기록을 삭제한다 |
| 홈 화면 | 오늘 기록 조회 | 오늘(로컬 새벽 5시 이후)의 카페인 기록 목록을 조회한다 |
| 홈 화면 | 오늘의 카페인 현황 | 잔류량 시계열 차트(15분 간격)·현재 잔류량·취침 시 예상 잔류량·총 섭취량(400mg 초과 여부)·섭취 마감시각을 서버가 계산해 제공한다 (잔류량·마감시각은 새벽 5시 경계와 무관하게 최근 24시간 기록으로 계산, 합계는 오늘 기록만) |
| (화면 없음 — 자동 동기화) | 수면 샘플 업로드 | 기기에서 읽은 HealthKit 원시 수면 샘플을 배치 업로드한다 (멱등 처리·같은 배치 동시 업로드도 한 번만 저장) |
| 수면 화면 | 수면 요약 조회 | 원시 샘플을 서버가 병합해 총 수면 시간·침대 시간·수면 효율·수면 잠복기(SOL)·단계별 시간을 계산해 제공한다 |
| (화면 없음 — 자동 실행) | 반감기 학습 실행 | 최근 7일의 미학습 밤에 대해 카페인 잔량과 수면 잠복기로 개인 반감기를 베이지안 학습하고 설정에 반영한다 (동시 실행돼도 밤마다 한 번만 학습) |
| 학습 대시보드 화면 | 학습 관측 이력 조회 | 날짜별 학습 관측 기록을 조회한다 |
| 학습 대시보드 화면 | 학습 대시보드 | 최신 반감기 추정(95% 신뢰구간·신뢰도)·모델 정확도(R²·RMSE)·잔량/SOL 히스토그램을 서버가 계산해 제공한다 |
| (화면 없음 — 로컬 알림) | 알림 계획 조회 | 예약할 로컬 알림 목록(종류·시각·문구)을 서버가 계산해 제공하고 앱이 그대로 예약한다 |
| (화면 없음 — 로컬 알림) | 섭취 마감 알림 | 오늘의 카페인 현황에서 계산한 섭취 마감시각 30분 전 알림을 계획에 포함한다 (마감 없음·이미 초과·30분 미만 남음이면 제외) |
| (화면 없음 — 로컬 알림) | 취침 잔량 예고 | 취침 시 예상 카페인 잔량이 50mg 이상이면 취침 60분 전 알림을 계획에 포함한다 (기록 없음·50mg 미만·60분 전 지남이면 제외) |
| (화면 없음 — 로컬 알림) | 기록 리마인더 | 오늘 기록이 없으면 최근 14일 일별 첫 기록 시각의 중앙값 + 2시간에 알림을 계획에 포함한다 (기록 있는 날 5일 미만·시각 지남이면 제외) |
| (화면 없음 — 로컬 알림) | 카페 근처 금지 구간 | 카페 근처 알림이 켜져 있으면 "이 구간에 카페 구역에 들어서면 울릴" 금지 구간을 계획에 포함한다. 끝은 하루 경계(다음 05:00), 시작은 사유별로 다르고 하루 한 구간 (취침 잔량 이미 50mg 이상이면 지금부터·하루 400mg 초과면 지금부터·마감 시각이 있으면 마감부터·마감 없음이고 400mg 이하면 제외. 기록 없는 다음 날의 기본 구간도 함께) |
| 인사이트 화면 | 기간별 섭취 통계 | 지정한 기간(최대 31일)의 섭취일별 총량·기록 수·첫/마지막 섭취 시각과 요약 문장을 서버가 계산해 제공한다 (섭취일은 로컬 05:00 경계·기록 없는 날도 0으로 포함·평균·최대·400mg 초과 일수·마지막 섭취 시각 평균은 기록 있는 날만이고 섭취일 기준 오늘(00:00~04:59 에는 달력 전날)과 그 이후 날은 제외·그런 날이 없으면 null·400mg 초과는 400 초과만·마지막 섭취 시각 평균은 05:00 기준으로 평균해 자정을 넘긴 섭취가 평균을 끌어내리지 않음·from > to·31일 초과·to가 오늘(달력 날짜) 이후면 400) |
| 인사이트 화면 | 카페인·수면 상관 리포트 | 기간(최대 31일) 안의 밤마다 취침 잔량·마감 준수와 수면 지표를 모아 "취침 잔량 50mg 이상/미만"과 "마감 시각 넘김/지킴" 두 비교와 문장을 서버가 계산해 제공한다 (수면 데이터나 inBed 시작이 없는 밤은 제외·잔량은 요청 시점 유효 반감기와 취침 전 24시간 기록으로 계산·마감 판정은 짝지은 섭취일(전날 05:00 ~ 당일 05:00) 취침 전 마지막 잔을 그 이전 기록과 현재 기준 용량으로 판정·섭취 없는 밤은 마감 비교에서 제외·5밤 미만이면 표본 부족이어도 밤 목록은 내림·그룹당 3밤 미만이면 비교 부족·SOL 비교는 그룹당 SOL 있는 밤 3밤부터·SOL 차이 5분 이상 또는 효율 차이 3%p 이상이면 차이 있음 문장·SOL은 같은 날 수면 요약과 같음·다른 사용자 데이터 미포함) |

## 예정

이름만 기록한다. API 형태·스키마는 착수할 때 `api/api.md`·`api/openapi.yaml`·`db/db-schema.sql`에 적고 구현과 함께 머지한다.

| 화면 | 기능 | 설명 |
|---|---|---|
| 기록 입력 화면 | 섭취 시뮬레이션 | 아직 기록하지 않은 음료를 마셨을 때의 예상 잔량을 미리 계산한다 |
| 기록 입력 화면 | 안전 섭취량 역계산 | 특정 시각에 마셔도 취침 잔량 기준을 넘지 않는 최대 카페인량을 계산한다 |
| 감량 플랜 화면 | 카페인 감량 플랜 | 목표 섭취량을 단계적으로 낮추는 계획을 세우고 진행 상황을 추적한다 |
| 설정 화면 | 비밀번호 변경 | 현재 비밀번호를 확인하고 새 비밀번호로 변경한다 |
| 설정 화면 | 회원 탈퇴 | 계정과 계정에 속한 데이터를 삭제한다 |
